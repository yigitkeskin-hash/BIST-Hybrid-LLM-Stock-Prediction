# 📈 BIST Stock Price Prediction: Hybrid PyTorch & Local LLM Pipeline

An end-to-end quantitative research pipeline for predicting Turkish stock market (**Borsa Istanbul - BIST**) stock prices by combining **historical technical indicators** with **offline Local LLM-powered sentiment analysis**.

Unlike traditional forecasting approaches that rely solely on historical prices, this project integrates **financial news sentiment** generated by a **local Phi-3.5-mini language model**, enabling privacy-preserving sentiment analysis without any cloud APIs.

The forecasting models are implemented in **PyTorch** using both **LSTM (Long Short-Term Memory)** and **GRU (Gated Recurrent Unit)** neural networks.

---

# 🚀 Features

- Fully automated end-to-end forecasting pipeline
- Historical BIST stock price collection via **yfinance**
- Technical indicator generation (RSI & SMA-20)
- Offline financial news sentiment analysis using **Microsoft Foundry Local + Phi-3.5-mini**
- SQLite database for storing market data and sentiment
- Time-series preprocessing with sliding windows
- PyTorch implementation of LSTM and GRU models
- Performance comparison using RMSE
- Visualization of actual vs. predicted stock prices

---

# 📊 Pipeline Overview

## Phase 1 — Database Initialization

Creates a local SQLite database (`bist_hybrid.db`) containing dedicated tables for:

- Daily stock prices
- Financial news
- Sentiment scores

---

## Phase 2 — Data Collection & Technical Indicators

Downloads one year of historical market data for major BIST companies:

- FROTO
- ASELS
- TUPRS
- THYAO
- SAHOL

The pipeline automatically computes:

- RSI (Relative Strength Index)
- SMA-20 (20-Day Simple Moving Average)

These indicators are later combined with sentiment features.

---

## Phase 3 — Local LLM Sentiment Analysis

Financial news headlines and article content are analyzed **completely offline** using:

- Microsoft Foundry Local
- Phi-3.5-mini

A **Few-Shot Prompting** strategy is employed to generate a normalized sentiment score ranging from:

- **-1.0** → Very Negative
- **0.0** → Neutral
- **+1.0** → Very Positive

Since inference runs locally, no financial data is sent to external services.

---

## Phase 4 — Data Preprocessing

The numerical and textual features are merged into a unified dataset.

Processing steps include:

- Merge closing prices with sentiment scores
- Min-Max normalization to **[-1, 1]**
- 20-day sliding window creation
- 80/20 train-test split

Each training sample consists of:

- Scaled closing price
- Sentiment score

over the previous **20 trading days**.

---

## Phase 5 — Deep Learning Forecasting

Two recurrent neural network architectures are implemented in PyTorch:

### LSTM

- 2 hidden layers
- Hidden dimension: 32
- Fully connected output layer

### GRU

- 2 hidden layers
- Hidden dimension: 32
- Fully connected output layer

Training configuration:

| Parameter | Value |
|-----------|-------|
| Optimizer | Adam |
| Learning Rate | 0.01 |
| Loss Function | Mean Squared Error (MSE) |
| Epochs | 60 |

The models are evaluated using **Root Mean Square Error (RMSE)**.

# 🧠 Model Input

Each model receives a sequence of **20 consecutive trading days**, where each day contains two features:

1. Scaled Closing Price
2. Sentiment Score

Input shape:

```
(sequence_length=20, features=2)
```

# 📈 Experimental Results

The models were evaluated on five major BIST stocks.

Overall, the **GRU architecture consistently outperformed the LSTM model**, achieving lower RMSE values while also requiring slightly less training time.

| Ticker | Company | LSTM RMSE | GRU RMSE | Best Model |
|--------|---------|----------:|---------:|------------|
| FROTO | Ford Otosan | 1.90 | **1.46** | GRU |
| ASELS | Aselsan | 20.69 | **14.02** | GRU |
| TUPRS | Tüpraş | 16.60 | **8.46** | GRU |
| THYAO | Turkish Airlines | 6.77 | **6.22** | GRU |
| SAHOL | Sabancı Holding | 1.83 | **1.80** | GRU |
